CarShare is a web application engineered to solve local transit bottlenecks around campus and reduce commute friction by connecting students with peer ride-shares.

💡 Origin Story
This project was born out of a daily real-world challenge. After experiencing long wait times for campus shuttle buses, I manually validated a carpooling alternative by coordinating shared rides to nearby transit stations with fellow students. To scale this concept, I led a development team to build a web platform that pairs commuters with volunteer student drivers, backed by an integrated digital reward system to incentivize participation.

🛠️ Tech Stack
**Backend:** PHP 8
**Database:** MySQL (Relational Database)
**Environment:** XAMPP Localhost (Apache / MySQL)
**Frontend:** HTML5, CSS3, JavaScript

🚀 Core Features
1. **Ad-Hoc Ride Matching:** Connects campus commuters with volunteer student drivers heading toward local transit hubs (e.g., LRT stations).
2. **Automated Loyalty Engine:** Server-side PHP and MySQL logic that automatically calculates and credits digital reward points to a driver's balance upon ride completion.
3. **Commuter Request Flow:** A streamlined interface for commuters to view available drivers, request pickups, and track ride statuses.

🗄️ Database Setup & Installation

**Prerequisites**
[XAMPP](https://www.apachefriends.org/) with Apache and MySQL services running.
